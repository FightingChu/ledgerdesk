# v8 到 v10 的升级与回退

v9 新增不可变规则、批次规则选择、运行规则快照、结果整数投影、分页源证据、报告配置和常用筛选。v10 新增本机任务、备份登记和工作空间设置。

旧结果 JSON、源导入、人工备注及审计保持原值。新查询表由旧结果事务回填，不把旧运行未知的规则快照补造成默认规则。未选择规则的旧批次保留原输入身份。

升级前使用 SQLite 在线备份产生数据库旁的唯一文件；DDL、回填、外键检查和 user_version 更新在同一事务中提交。失败回滚，未来版本拒绝打开。

```powershell
python scripts/check_migration.py ./data/ledgerdesk.sqlite3
python -m ledgerdesk --diagnose
```

第一条只迁移临时副本，并按原列逐表比较摘要与数量，不打印订单或备注。正式升级前先停止所有旧服务，保留自己的独立备份。

回退必须先停止服务，把升级前备份恢复到新的数据目录，再使用兼容版本启动。不能用旧程序打开已升级数据库；不要手工降低 user_version。

源证据投影重复保存运行时的标准化行，数据库会随历史运行增长。当前不自动删除历史运行或其证据。
