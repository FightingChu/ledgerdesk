# 完整流程速用

双击 `start.cmd`，或运行 `python -m ledgerdesk --open`。当前仍是单人本机工具，服务固定绑定回环地址。

1. 创建样例批次，或用标准 CSV 创建自己的独立批次。
2. 导入业务单与支付账单，完成文件、字段、整份校验和确认四步。
3. 保持默认精确核对，或在“核查规则”明确选择不可变规则修订。
4. 执行核对。需要后台执行时使用“后台核对”，到“本机任务”查看结果。
5. 在当前页勾选异常，填写共享依据后批量处理；查看订单时源行按页加载。
6. 通过“渠道统计”查看与当前筛选一致的金额、分组和异常数量。
7. 选择报告配置，导出 CSV、打开打印报告，或后台生成报告后下载。
8. 在数据管理中创建并校验备份。恢复始终使用新目录。

“容差内待复核”仍然属于异常，人工处理不改变实际差额。工作台按独立批次展示，不能把重复输入的批次金额相加当作经营收入。

较大报告建议使用后台任务。服务退出时没有完成的任务会被识别为中断，输入未变化时可明确重试。默认库无需为了体验而清空，验证请使用独立目录。
