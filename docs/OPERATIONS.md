# 本机维护流程

启动前确认版本与数据目录；同目录旧版进程应先退出。使用 `--diagnose` 做只读检查，升级先保留独立备份。

日常操作后创建并校验手动备份。需要启动备份时在页面保存启用策略，默认不启用。保留数最少1份；清理前必须先保存想要的策略。

执行器使用数据目录下的 `.ledgerdesk-worker.lock`。锁文件可以长期存在，存在本身不代表仍被锁定；不要通过删除锁文件强行启动第二个执行器。正常退出会释放 OS 锁。

任务失败先看状态、阶段和可读错误。输入变化时创建新任务；输入未变的失败/中断任务可重试。已提交核对不会因为关闭服务而撤销。

备份恢复使用新目录，并换端口检查原批次、处理状态和历史。确认恢复点可用后再决定后续使用哪个目录。当前恢复不会自动切换运行服务。

当前没有自动历史压缩、云同步、数据库轮换或跨机器任务执行。不要把源码仓库当作业务数据备份。
