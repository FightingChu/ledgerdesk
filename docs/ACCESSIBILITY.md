# 键盘与窄屏

批次行可用 Enter/空格打开。按钮、链接、选择框、复选框和原生对话框使用可聚焦控件，焦点有可见轮廓；新对话框通过标题关联名称。

结果选择限制为当前页，已选择数量使用实时状态区域。分页按钮表达首末页状态。错误提示使用 alert，导入步骤标记当前步骤。原生 dialog 支持 Escape，保存操作进行中会阻止关闭以避免误判状态。

宽表在独立滚动区域内横向滚动。手机宽度下工具栏与确认按钮换行，整体页面不应横向溢出。减少动态效果偏好会关闭非必要过渡。

发布前检查 390px 宽度的导入、规则、报告编辑、任务列表与证据页。检查不只依赖截图，还读取文档宽度和实际控件状态。

当前未宣称通过完整 WCAG 合规审计或屏幕阅读器全流程验收；发现可复现的障碍应作为产品缺陷处理。
