# 常见问题处理

| 现象 | 处理 |
| --- | --- |
| 端口被占用 | 使用另一个端口；不要假定相同页面来自相同数据目录 |
| 提示旧版本服务 | 停止旧进程，再用当前版本启动 |
| 结果过期 | 检查新增/撤销/替换文件与规则选择，重新核对 |
| 处理版本冲突 | 保留本次依据，重新加载详情或刷新后重新选择 |
| 导入校验凭据失效 | 回字段步骤重新确认并校验 |
| 排队任务提示输入变化 | 提交新任务，不绕过输入身份检查 |
| 任务一直等待 | 确保网页服务或 CLI 执行器在运行；同工作空间只能有一个执行器 |
| 中断任务 | 检查错误和原输入，明确重试；成功任务不能重试 |
| 报告目标已存在 | 使用新输出文件；任务报告不覆盖既有文件 |
| 备份被跳过清理 | 文件可能未登记、已改动、损坏或缺失；不会强行删除 |
| 数据库版本过高 | 使用支持该版本的程序，或把旧备份恢复到新目录 |

先使用 `python -m ledgerdesk --diagnose`。诊断不会初始化缺失的数据库。不要手工修改版本号、删除默认数据库或把原始账单贴到公开 Issue。

仅为复现而操作时，复制到新数据目录，明确标注合成或本机验证；保留原库与恢复点。
