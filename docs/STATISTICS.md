# 统计与工作台口径

渠道统计使用固定运行的紧凑整数金额投影，复用结果列表的分类、异常、状态和字面搜索条件。总数与渠道页在同一个只读事务中计算，每页最多 100 个渠道。

预计金额、实际净额、差额、收款和退款均先以整数分聚合，再格式化为元。金额一致只指 reasons 为 matched；容差命中仍计入异常。

一个订单可能同时有多个异常，因此按类型的异常计数可以重叠。渠道分组数可以求和；异常类型计数不应强行相加等于订单分组数。

当前处理状态为本次请求时的实时状态，历史统计使用运行时快照。没有旧快照时保持未知，不反推过去。跨请求翻页不冻结实时处理状态。

工作台按批次展示最新运行、是否过期及金额摘要。批次可能包含同一文件或同一业务期间的不同核查版本，不提供未经去重的经营收入总额。

```powershell
python -m ledgerdesk stats
python -m ledgerdesk stats BATCH_ID --status outstanding
python -m ledgerdesk stats BATCH_ID --run-id RUN_ID --historical
```
