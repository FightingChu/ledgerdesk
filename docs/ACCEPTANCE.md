# 本地候选版验收清单

本文件定义工程检查，不是客户验收记录。实际执行结果、环境和问题保存在被忽略的本地验证记录。

- 空工作空间可创建批次、导入两侧标准文件并核对。
- 字段候选、错误分页、校验凭据和原子替换符合导入契约。
- 默认精度不回退，容差命中仍为待复核，规则与历史可解释。
- 统计遵循当前筛选，按渠道分页，旧状态缺失不猜造。
- 单项与批量处理有版本冲突，失败整批回滚。
- 订单证据和历史比较有响应上限，CSV/HTML 包含全部匹配结果。
- 报告配置顺序可保存，用户文本转义，后台报告可下载。
- 任务去重、取消、重试、中断与完成发布恢复均有回归。
- 备份保留不删除未知文件，最后健康恢复点保留。
- CLI 与 HTTP 使用同一业务规则，公开资源不能读取源码或本机数据。
- 旧库副本迁移原值保留，干净包和四组 CI 通过。
- 手机布局无整页横向溢出，关键控件可用键盘操作。

只有具备真实渠道样例和外部实际反馈后，才能另外评估稳定1.0资格；文件数不会替代这些事实。
