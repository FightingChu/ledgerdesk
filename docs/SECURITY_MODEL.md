# 本机运行边界

LedgerDesk 面向单人本机使用，不提供公网认证、多用户权限、远程账户或不可篡改审计。固定回环绑定、可信 Host、本机 Origin 和会话 token 用于降低浏览器跨站写入风险，不构成多人服务方案。

静态资源使用显式允许列表。源文件、数据库、任务 payload、备份、日志和导出留在本机，不进入源码包。错误只向页面返回可读信息，详细异常仅在本机日志。

报告配置只允许已知列键；HTML 用户文本转义，CSV 用户文本公式转义。报告固定样式以 CSP 哈希放行。任务只能执行核对、报告或备份，报告输出只使用任务专属名称。

恢复不覆盖已有目录。任务文件使用不覆盖发布；工作空间执行器用 OS 文件锁互斥。保留策略只处理登记并校验通过的备份，未知文件保留。

能修改本机数据库或源码的用户仍能改变业务数据与审计。工具不宣称具备取证防篡改或身份归属认证。部署边界变化时须重新设计认证、授权和运维。
