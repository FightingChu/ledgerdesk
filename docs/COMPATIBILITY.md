# 兼容性与版本范围

最低 Python 3.10。CI 覆盖 Windows/Ubuntu 的 Python 3.10 与3.12。无需运行数据库服务、前端打包器或外部任务队列。

支持已标记 v1～v8 的旧库依次升级至 v10；未来版本拒绝写入。旧运行没有规则或处理快照时继续未知，旧导入没有适配器版本时继续未知。

`Store.detail`、`case_detail`、`run_detail`、`compare_runs` 的旧批量接口保留。新页面使用摘要、分页源证据和流式导出，旧函数的整批内存行为不被伪装为已优化。

原 `preview`、`parse` 和 `decode_file` 保留。单项 HTTP 处理从0.7起须提供运行和处理版本；旧 Python 处理签名仍可调用，但省略版本参数时采用最后写入生效语义。

导入向导使用带时效凭据，旧直接 HTTP/Python 导入可省略凭据但仍完整校验。标准 CSV v1 是本工具约定，不代表原始渠道账单适配。

恢复和源码回退是两件事：用旧源码时应打开对应升级前备份的新副本，不能手动降低数据库版本号。
