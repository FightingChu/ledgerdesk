# 当前边界

LedgerDesk 面向单人本机运行，默认服务绑定回环地址。源码包和示例不包含数据库、备份、导出或原始账单。

当前只支持人民币标准 CSV。单文件限制为 5 MiB、10000 行、80 列；不自动汇兑、拉账、结算、分账或解释手续费和跨期归属。其他渠道需要明确格式版本与字段契约。

分页查询、流式报告和比较缓冲有单次容量上限；核对本身和旧兼容批量函数仍可能使用随输入量增长的内存。长期下载会保持 SQLite 读快照。

任务执行器位于本机进程，服务退出时未完成任务不会在外部继续运行。取消在安全检查点生效，不撤销已提交业务事务。

不自动删除历史运行、原证据或用户导出。备份清理仅处理明确登记并校验通过的文件；未知、已改动或损坏的文件保留。

账户与访问控制采用单人本机运行边界，操作记录用于本机追溯。扩展为公网或多人服务时，需单独设计认证、授权和运维。
