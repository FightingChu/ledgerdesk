# 当前明确边界

仍是单人本机候选产品，没有真实客户、付费交付或生产运行证据。公开账单和金样均为合成输入，尚无微信、支付宝原始账单适配。

只支持人民币标准 CSV。单文件5 MiB、10000行、80列，不自动汇兑、拉账、结算、分账或解释手续费和跨期归属。

分页查询、流式报告和比较缓冲有上限；核对本身和旧兼容批量函数仍可能使用随业务量增长的内存。长期下载会保持 SQLite 读快照。

任务执行器位于本机进程，服务退出时未完成任务不继续在外部运行。取消是安全检查点语义，不撤销已提交业务事务。进度不是核对内部每行的精确百分比。

不自动删除历史运行、原证据或用户导出。备份清理仅处理明确登记并校验的文件。未知、已改动或损坏的文件保留供人工核查。

没有公网权限、多用户身份、审计防篡改或完整无障碍合规认证。代码测试通过不能用来声称上述能力已完成。
