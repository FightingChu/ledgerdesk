# 版本记录

## 0.5.0 — 2026-10-19

- 按现有数据条件调整本轮交付为本地数据保护，真实渠道适配仍等待真实格式样例验证。
- 新增浏览器数据管理入口：创建并校验备份、手动备份列表、重新校验、恢复到全新目录与只读诊断导出。
- 新增 `--diagnose` 和 `--restore ... --restore-to ...`，诊断不会创建源库，恢复不启动或切换服务。
- 诊断识别缺失、损坏、非本产品结构、外键异常和未来版本；报告不含订单、备注、文件名和本机路径。
- 备份计数与复制共享同一快照；生成独立 SQLite 备份，避免恢复临时文件留下 WAL 附属文件。
- 恢复拒绝全部已有目录，使用校验后的临时副本及不覆盖目标的发布方式，失败只清理本次创建的文件。
- 沿用 schema v5，无需迁移默认库；原账单和核对规则不变。
- 不再复用相同目录中的其他版本服务，避免升级后新页面调用旧服务接口。
- 新增故障、恢复、路径限制、并发快照、CLI 和 HTTP 数据保护回归，自动测试总数为 98 项。


## 0.4.0 — 2026-10-19

- 抽出领域规则、核对应用服务、CSV 报告、迁移/备份及模板/运行仓储，保留 Store 兼容入口。
- 修复当前筛选导出丢失顶部分类、未完成状态和搜索条件；导出校验页面运行版本，拒绝无效筛选参数。
- 修复相同文件更改渠道别名时被当作重复导入；新导入保存原渠道，旧库原渠道保持未知。
- 模板保存前校验完整映射和别名冲突，新增修订号、复制、删除、事务导入和便携 JSON 导出。
- 历史版本按批次校验，显示差异明细和旧源行；新增运行时处理快照，旧快照缺失时明确显示未记录。
- 批次增加标签、归档、恢复、搜索和摘要。归档后保留数据及导出，暂停输入与处理修改。
- 新增严格的 version=1 JSON 配置、命令行覆盖和无副作用配置检查。
- schema v5 迁移前自动备份；增加 v4 迁移失败回滚、跨层边界、业务规则及 HTTP 回归。
- CI 增加 Windows 和 Ubuntu 矩阵，以及解压后运行完整测试的发布包验证脚本。


## 0.3.0 — 2026-10-18

- 新增 schema v3 → v4 迁移和映射模板表。
- 导入时可复用字段映射模板，并配置渠道别名；别名在源文件写入前规范化，原配置保留在文件记录。
- 批次详情展示历史核对运行，支持比较两次运行中的新增、消失和变化记录。
- 导出支持全部记录或按异常类型、处理状态筛选。
- 增加 MIT License 和 GitHub Actions，自动在 Python 3.10、3.12 上运行测试。


## 0.2.0 — 2026-10-18

- 新增导入文件撤销和原子替换，保留旧文件、源行、核对历史和操作原因。
- 撤销/替换前自动备份，失败时不改变有效文件；备份 CLI 拒绝不存在的源数据库，不再生成空备份。
- 新增 schema v2 → v3 迁移、输入版本和有效文件状态；旧库数据逐表保留。
- 修复跨订单重复流水的证据范围，新增冲突订单源行；相关异常变化后重新待处理。
- 自动映射遇到同义候选列时取消默认选择，要求用户明确确认。
- 结果页增加异常类型和处理状态筛选，导出明确导出全部核对记录。
- 页面显示已撤销/已替换文件和替换、撤销操作入口。
- 新增 13 项导入生命周期与备份回归测试，总测试数为 59 项。

## 0.1.1 — 2026-10-18

- 修复币种列大小写和别名识别；预览检查全文件币种，显示实际值或默认人民币口径。
- 拒绝空白、未知、非人民币和冲突币种列；CNY、RMB、人民币可等价使用。
- 新增 schema v1 → v2 的事务迁移和升级前自动备份；备份失败停止升级，迁移失败回滚，高版本库拒绝写入。
- 保留旧结果与备注，旧导入标记为币种未重新核验，新导入记录明确币种或默认人民币的依据。
- 启动复用校验应用标识、实例协议和规范化数据库路径；不同目录明确报错。
- Windows 使用独占端口，端口冲突时先报错，再决定是否打开数据库。
- 运行时、页面、包元数据与发布包读取同一版本定义；发布脚本采用显式文件清单，排除临时文件和额外 CSV。
- 新增 16 项回归测试，仍为个人验证版，未新增真实客户或生产使用记录。

## 0.1.0 — 2026-10-18

- 新增本地浏览器工作台，无第三方运行依赖。
- 新增独立批次、UTF-8/GB18030 CSV 预览和字段映射。
- 新增精确整数金额、退款净额、重复和单边缺失识别。
- 新增源文件幂等导入、整份校验、事务入库和处理留痕。
- 新增证据变化后重新待处理、过期结果禁止备注与导出。
- 新增带 BOM 的 CSV 导出、源文本公式转义和数据库备份。
- 首版仅完成个人验证，无真实客户或生产交付记录。
