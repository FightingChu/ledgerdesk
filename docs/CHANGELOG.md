# 版本记录

## 0.13.1 — 2026-10-19

- 增加批次操作记录导出，支持 CSV/JSONL、操作类型筛选和固定事件上限；页面、HTTP 与 CLI 共用同一导出服务。

## 0.13.0 — 2026-10-19

- 连续交付剩余扩展阶段：不可变规则与显式容差、渠道统计、工作台和常用筛选；容差命中仍保持待复核。
- schema v9/v10 新增规则/运行快照、整数金额和分页源证据投影、报告配置、任务、备份登记与设置，原业务列与结果JSON保留。

- 增加完整业务CLI、明确启用的启动备份与已登记恢复点保留策略，保护未知文件和最后健康备份。
- 增加12组合成金样、事务/并发/迁移/HTTP/CLI/故障回归及工程工具，共222项测试，公开源码292文件。
- 保持单人本机候选状态；真实渠道、外部试用与1.0资格未由本次工程扩展替代。

## 0.8.0 — 2026-10-19

- 导入和替换改为文件、字段、整份校验、确认四步；显示编码、缺失/冲突字段及模板覆盖建议，模板须人工选择。
- 完整校验提供全部无效行的分页查看和 CSV 下载，最终提交前不写入业务内容；旧解析入口继续保留前 30 条错误的兼容格式。
- 新向导使用 10 分钟签名校验凭据，绑定文件、映射、别名、批次输入版本及替换信息；变更和重启后要求重新校验。
- 提取 ingestion 共用读取/币种/映射诊断/行校验，建立实际使用的 standard_csv v1 适配协议与注册入口，未知版本拒绝。
- schema v8 增加导入适配器身份，旧版本保持未知；原数据与处理历史保留。旧直接导入调用仍执行整份校验。
- 新增编码、多行源行号、完整错误、预检无写入、过期/篡改/跨批次凭据、替换回滚、旧库迁移及 HTTP 回归，自动测试共 149 项。

## 0.7.0 — 2026-10-19

- 当前结果页支持选择本页差异、批量更新处理中/已处理和共享备注，每次最多 100 项；翻页、筛选、刷新和切换批次清空选择。
- 单项及批量 HTTP 保存绑定运行、证据和整数处理版本；任一项冲突或写入失败时整批回滚，重复提交不产生重复成功审计。
- schema v7 为旧备注初始化处理版本 1，未处理为 0，新增批次/类型审计索引；迁移前备份并保留全部原列、结果及历史快照。
- 操作记录支持按类型筛选和固定事件上限分页，保存处理前后状态、备注、版本及关联批量汇总。
- 提取批次、导入、处理的应用服务与仓储，保留 Store 兼容入口；页面增加批次、处理和审计控制器。
- HTTP 单项处理须新增 run_id 和 expected_revision；Python 原签名仍可调用，省略版本参数时不提供备注覆盖保护。
- 增加整批回滚、两个并发页面、同秒修改、重复请求、100 项边界、审计分页及旧库迁移故障回归；自动测试共 132 项。

## 0.6.0 — 2026-10-19

- 主页面改用批次概览与结果摘要分页，默认 50 项，可选 25/100；点击订单才加载完整源行。

- 新增 5001 个订单分组、大批次源行按需读取、并发备注、分页边界、历史比较和 v5 回填回滚回归。
- 数据诊断增加摘要数量覆盖检查，备份与恢复沿用已有保护规则。
- 自动测试共 112 项，本机 Python 3.10、3.12 均通过，包含 5001 组合成大批次和 API 回归。


## 0.5.0 — 2026-10-19

- 按现有数据条件调整本轮交付为本地数据保护，真实渠道适配仍等待真实格式样例验证。
- 新增浏览器数据管理入口：创建并校验备份、手动备份列表、重新校验、恢复到全新目录与只读诊断导出。
- 新增 `--diagnose` 和 `--restore ... --restore-to ...`，诊断不会创建源库，恢复不启动或切换服务。
- 诊断识别缺失、损坏、非本产品结构、外键异常和未来版本；报告不含订单、备注、文件名和本机路径。
- 备份计数与复制共享同一快照；生成独立 SQLite 备份，避免恢复临时文件留下 WAL 附属文件。
- 恢复拒绝全部已有目录，使用校验后的临时副本及不覆盖目标的发布方式，失败只清理本次创建的文件。
- 沿用 schema v5，无需迁移默认库；原账单和核对规则不变。
- 不再复用相同目录中的其他版本服务，避免升级后新页面调用旧服务接口。
- 新增故障、恢复、路径限制、并发快照、CLI 和 HTTP 数据保护回归，自动测试总数为 98 项。
