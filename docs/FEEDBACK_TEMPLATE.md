# 使用反馈记录模板

以下字段用于填写实际反馈，避免将空白占位当作产品记录。

## 反馈事实

- 记录日期与记录人：待填写
- 使用方角色：待填写
- 使用阶段：试用 / 试点 / 正式使用，按实际填写
- 版本与提交：待填写
- 原工作方式与具体问题：待填写
- 对应数据范围及授权方式：待填写
- 输入样例位置与文件摘要：待填写
- 预期输出与实际输出：待填写
- 可复现步骤：待填写
- 影响范围：待填写

## 开发与验收

- 需求或缺陷单号：待填写
- 对应代码修改与测试：待填写
- 验收人员、日期及结果：待填写
- 交付或部署记录：待填写
- 后续反馈：待填写

业务身份、交易文件和合同原件应留在适当的私有资料位置。公开复现只使用获得授权的示例或独立编写的最小输入。
