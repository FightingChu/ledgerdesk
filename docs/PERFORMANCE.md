# 性能与资源边界

结果页、渠道页、源行页和差异响应均有单次容量上限。历史比较在 SQL 合并摘要后只保留当前差异页及末页缓冲，不加载完整源行数组。

CSV 和 HTML 分块输出，保持同一读快照。单行文本长度、单文件字节和行数仍受导入上限约束；缓冲有界不代表任意规模下的总时间恒定。

核对本身仍加载有效输入和前次证据，峰值内存随输入量增长。迁移需要扫描保存的历史结果，源证据物化也增加存储量。不能把分页接口宣传为整个程序任意规模内存恒定。

```powershell
python scripts/benchmark.py --sizes 5000 --out ./backups/benchmark-5000.json
python scripts/benchmark.py --sizes 20000 100000 --out ./backups/benchmark-large.json
```

基准仅生成示例输入，按每文件最多 10000 行分批导入，记录 Python/系统、各阶段耗时、Python 跟踪分配峰值与 CSV 大小。tracemalloc 数值不是进程 RSS，也不适合跨不同机器直接比较。

每次只针对具体风险重复测量。大规模基准不放进每次 CI，不把尚未执行的规模写成已通过。发布前的实际测量保存在本机验证记录，公开文档不虚构性能门槛。
